# SourceGate 使用说明

先将项目包完整解压，双击 SourceGate_App.html 打开 App，双击 SourceGate_Deck.html 打开15页说明演示。建议桌面 Chrome 或 Edge；若浏览器限制本地电子签署，请按 project/README.md 使用 localhost 或 HTTPS。

默认数据为虚构样例。上传文件只保存在当前浏览器；本原型未接入真实企业认证、第三方核验和正式入库。

完整项目、评分标准、实施方案及测试见 project 文件夹。

在线发布未完成，浏览器交互验收未完成；自动化规则及界面生成检查已通过。详见 project/docs/VERIFICATION.md。
