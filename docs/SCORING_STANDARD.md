# 六维供应商准入评分标准（建议 CAPEX v1.0）

所有分档按达到阈值判定，低于首档为0分。单指标只有0/40/60/80/100五档。每维独立最低60分，总分75分建议准入，60至不足75分有条件准入；证据、签署身份、签名和澄清未完成时保持待核验。正式准入仍须授权审批。

## 计分与证据

维度分=Σ(子指标档位分×维度内权重)；总分=Σ(维度分×总权重)。判定使用未四舍五入的计算值。申报分用于预览；核实分只接受经审核的完整维度证据包。证据未确认的维度核实分暂为0，系统状态保持待核验，不把未知事实直接等同于已确认不合格。

## 三年财务

每年流动比率=流动资产/流动负债；每年权益资产比=权益/总资产；分别取三年最低值，经营现金流统计为正年数。三年必须为不同的完整财年，币种、单位和实体口径一致；流动负债和总资产须大于零。报表本身及审计意见必须核实。负权益、保留/否定审计意见和持续经营疑虑进入专项澄清，不以数字评分替代财务判断。

## 清单定义

环境：环境方针、能耗基线、量化减排目标、外部核查。

劳动与安全：劳动政策、安全培训、事件记录、整改闭环。

治理：反贿赂、举报机制、利益冲突申报、管理层审查。

业务连续性：LLE交期台账、应急预案、演练记录、次级供应商映射。

质量：有效QMS、ITP/FAT、追溯记录、内审与纠正。

完成项必须同时有文件和执行证据。强制合规事项和关键技术规格另设准入硬门槛。所有默认阈值均为待公司批准的建议，不是ISO或监管统一要求。
